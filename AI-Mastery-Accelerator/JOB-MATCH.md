# Copertura della posizione AI Engineer

Questa matrice trasforma la descrizione del ruolo in competenze verificabili. Non
basta completare le letture: per dichiarare una voce coperta serve la prova indicata.

| Requisito | Modulo | Prova da portfolio |
|---|---|---|
| Agenti multi-step e orchestrazione | 05 | LangGraph con branching, checkpoint e stop condition |
| Ragionamento e gestione errori | 05, 07 | suite di failure scenario e recovery idempotente |
| MCP per contesti, tool e knowledge | 06 | server MCP con resource, tool, auth e test |
| Chatbot/agenti nel prodotto | 07, 08 | API versionata, canary, tracing e SLO |
| Preparazione dati RAG | 04, 06 | parsing, qualità, ACL, deduplica e lineage |
| Knowledge base aggiornata | 06 | DAG incrementale con versioning e rollback indice |
| Data platform per workload AI | 06 | dlt + Snowflake + dbt + Airflow |
| Ownership full-stack | 08 | ingestion, dominio, API, infrastruttura e runbook |
| Python solido | 01 e tutti i lab | package tipizzato, async, test e profiling |
| LangChain e dintorni | 04, 05 | componenti LangChain e graph LangGraph |
| ML training/tuning/deploy | 02, 03, 07 | esperimenti tracciati, API e monitoring |
| Docker e AWS | 06, 07, 08 | immagine non-root e deploy ECS/Fargate |
| Metabase | 06 | dashboard qualità/freschezza/costo |

## Priorità per il colloquio

1. **Must-have:** Python, RAG eval, LangGraph, MCP, pipeline incrementale, Docker.
2. **Working knowledge:** dbt, Snowflake, dlt, Airflow, AWS e osservabilità.
3. **Contesto:** Metabase; è utile per dashboard, ma non è il centro del ruolo AI.

## Gap che un corso non può colmare da solo

I requisiti temporali ("3+ anni", "1 anno su AI") richiedono esperienza reale. Riduci
il gap con un capstone usato da persone vere, manutenzione continuativa, incidenti
documentati, contributi open source e risultati misurabili. Non presentare la durata
del corso come esperienza professionale.
